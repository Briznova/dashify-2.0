**File:** [DASHIFY FIGMA DESIGN](https://www.figma.com/design/p7RzNrLkp2EEu5eFo91sky/DASHIFY-FIGMA-DESIGN?node-id=0-1)

**Checked:** 2026-11-13 via Figma MCP metadata

The file originally contained 38 screen and UI frames on **Page 1**. Teacher
screens were moved to a separate **Teacher** page, and the School Admin
screens were moved to a separate **School Admin** page. The remaining role
groups and shared screens remain on **Page 1**. Figma's Starter plan limits
the file to three pages, so separate pages for the other roles remain blocked.
The links below identify the frames observed in the file; they are visual
references, not evidence that the depicted functionality is implemented or approved.
Consult the [role workspace design](./05b-role-workspace-design.md) and
[Phase 5 specs](./05a-phase5-proposed-specs.md) for product and implementation
status.

## Using this reference

- Inspect the relevant frame and its states before implementing a screen; this
  index is based on frame names and structure, not a detailed visual review.
- Treat product behavior, data boundaries and authorization in the approved
  specs and backend contracts as authoritative over the design.
- Keep proposed or unsupported features gated; do not expose mock data as live
  data or infer permissions from the Figma screen.
